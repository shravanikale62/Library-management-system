# Library Management System

A Spring Boot based Library Management System with role-based login for Admin, Student and Librarian.

## Features

* User registration and login
* Role-based dashboard
* Admin dashboard
* Student dashboard
* Add, view, edit and delete books
* Issue and return books
* Fine calculation
* Student profile
* Reports page
* MySQL database integration

## Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* Thymeleaf
* HTML
* CSS
* MySQL
* Maven

## Database

Database file is included as library_db.sql.
